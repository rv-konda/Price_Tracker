# Live Price Tracker

A Python and Streamlit dashboard for monitoring stock prices using Yahoo Finance data. The tracker displays the latest available price, daily movement, and historical price performance for multiple ticker symbols.

## Features

- Tracks multiple stocks at the same time
- Refreshes prices automatically
- Displays the latest available price
- Shows daily dollar and percentage changes
- Provides interactive historical price charts
- Supports five chart ranges:
  - 1 day
  - 5 days
  - 1 month
  - 6 months
  - 1 year
- Records unique price observations in a CSV file
- Allows recorded snapshots to be downloaded from the dashboard
- Does not require an API key


## Important limitations

- Yahoo Finance data may be delayed.
- Prices may not update while the relevant market is closed.
- The application is intended for learning and personal research.
- It should not be treated as an exchange-grade real-time market-data system.
- The displayed information is not financial or investment advice.
